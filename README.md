# Ngrid Extractor 📦

[English](README.md) | [한국어](README.ko.md)

---
A python based tool for extracting AIMESH.NGRID files from League of Legends game file.

## About AIMESH.NGRID
AIMESH.NGRID is a binary data format that stores environmental grid details and technical specifications for League of Legends maps.
<br><br><br>
Path:  
**Riot Games > League of Legends > Game > DATA > FINAL > Maps > Shipping > <u>Map11.wad.client**</u>
